OPAC - Online Public Access Catalog

**OPAC (Online Public Access Catalog)** is a web-based library catalog that allows users to search, browse, and access information about the library's collection. It enables students, faculty, and staff to locate books, journals, theses, multimedia resources, and other library materials by title, author, subject, keyword, or call number. OPAC provides real-time availability, detailed bibliographic information, and an efficient way to discover and access library resources anytime and anywhere.
